# 鹈鹕骑车 · 傍晚海堤落日

纯 SVG + 原生 JS 的 2D 动画，单文件无依赖。

- 傍晚海堤落日场景，多层视差（云 / 岛屿 / 海面碎金 / 护栏 / 路灯 / 前景草）
- 鹈鹕有大喉囊，囊里装着一条会随颠簸晃动的鱼
- 自行车带 14 根辐条，双腿两段 IK 反解，真实踩踏曲柄
- HUD 实时显示速度 / 加速度 / 里程，含阻力与刹车物理
- 骑得越远，太阳越低，天色越暗

## 操作

| 操作 | 效果 |
| --- | --- |
| 按住 → / D / W / ↑，或长按画面 | 加速 |
| ← / A / S / ↓ | 刹车 |
| 空格 | 按铃（带声音与扩散波纹） |

直接用浏览器打开 `index.html` 即可。
